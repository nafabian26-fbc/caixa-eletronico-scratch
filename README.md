# 🏧 Simulador de Caixa Eletrônico

## Sobre o projeto
Projeto acadêmico desenvolvido no Scratch para praticar lógica de programação no curso de Análise e Desenvolvimento de Sistemas (ADS).

## Funcionalidades
- Solicitação de saque
- Validação de senha
- Verificação de saldo disponível
- Atualização do saldo após saque
- Mensagens de confirmação e erro

## Como executar
[▶ Clique aqui para testar o Caixa Eletrônico](https://scratch.mit.edu/projects/1387562066/)

Clique na bandeira verde e siga as instruções na tela.

## Tecnologias e conceitos
- Scratch 3.0
- Variáveis
- Estruturas condicionais SE/SENÃO
- Operadores lógicos e relacionais
- Entrada e saída de dados

## Objetivo
Demonstrar conhecimentos de lógica de programação por meio de uma simulação de operações bancárias.
